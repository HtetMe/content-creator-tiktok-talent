# Htet Me Me Hlaing Creator Portfolio

Static personal portfolio for TikTok Talent, Content Creator, and Script Writer applications.

## Files

- `index.html` - website content and page sections
- `style.css` - layout, responsive design, and visual styling
- `script.js` - mobile menu and scroll animations
- `assets/` - replaceable photos and videos

## Replace Media

- Profile photo: replace `assets/profile.jpg`
- KBZ acting video: replace `assets/acting-video-thumbnail.mp4`
- Optional profile placeholder: `assets/profile-placeholder.svg`
- Optional video placeholder: `assets/video-placeholder.svg`
- Gallery photos: replace the placeholder gallery blocks in `index.html` with `<img>` tags when photos are ready
- Professional photo placeholders are included as `assets/photo-placeholder-01.svg` through `assets/photo-placeholder-05.svg`

## Deploy

This is a static website, so it can be deployed directly to GitHub Pages, Vercel, Netlify, or any static hosting service.

For GitHub Pages, upload this folder to a repository and set Pages to serve from the repository root.
